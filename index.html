The problem

Feedback happens on a Figma frame, a screenshot, or an email — anywhere except the thing you actually shipped.

🖼️

Mockups go stale

How it works

Review the product, not a proxy for it

Send the real thing, not a Figma link — and get back a draft PR, not a comment thread.

1

Send the live product

Point Pin Point at your GitHub repo. It builds an instrumented preview of the actual site — no Figma link, no extension or login needed on their end.

2

They pin comments on it

Clients click elements on the real, live page and leave plain-language notes. Each one gets mapped back to the source file behind it.

directapproximateunresolved
3

You approve, agent fixes it

Review the mapped feedback in your dashboard and click Generate Fix PR. A coding agent implements it in an isolated worktree, runs your tests and build, then opens a draft PR.
